## Usage Guide

**This guide explains how to use GIMI and HSR-Fix to modify models and textures for Honkai: Star Rail, Genshin Impact, and Honkai Impact 3rd.**

**Note:** This tool supports multiple games, including:
- Honkai: Star Rail
- Genshin Impact
- Honkai Impact 3rd

These games all use Unity engine and similar vertex buffer structures, so the same tool can be used for model modification.

### Model Modification

Before reading, you need to understand the basic usage of GIMI and Blender. The detailed steps are:

1. Open the ModScripts/config/preset.ini file for configuration. There are several configurations that you need to fill in yourself. First, change LoaderFolder to the path where your 3dm d3d11.dll file is located. mod_name is the name of the generated ini file. It is recommended to use an English name such as Pela or Pela_v1.

2. Use F8 to dump files in the character interface, then use the numeric keypad 789 to find the IB corresponding to the character. Open the configuration file just now and continue to modify it. Fill in the found IB into draw_ib, change OutputFolder to the path where you want to export the txt model, and change FrameAnalyseFolder to the name of the dump folder generated by F8.

3. Open cmd or powershell in the ModScripts folder (shift+right-click menu has the option to open powershell here), and execute the first script:

   ```
   python ./Step1_Merge.py
   ```

   After successful execution, the corresponding data will be extracted, and textures and txt models will be generated to the OutputFolder path just set. If execution fails, please check the configuration and view the error.

4. Import the txt model into Blender, modify it, and then use the option: 3DMigoto raw buffers (.vb+.ib) to export. Note that it should be exported to the output folder configured earlier. It is recommended to use the name of the txt file for naming, such as body_part0. If there are multiple parts, you need to export them multiple times separately. Pay attention to the corresponding names.

5. Execute the second script:

   ```
   python ./Step2_Split.py
   ```

   After successful execution, buf files will be generated.

   Then execute the third script:

   ```
   python ./Step3_Generate.py
   ```

   After successful execution, ini files will be generated.

### Texture Modification

Refer to GIMI's textures for modification and configuration of ini files. Some textures need to be collected using the collect script.
